Chinook Music Store - SQL Analysis
About the Project
A simple SQL data analysis project using the Chinook music store database. The goal is to practice writing SQL queries to explore customer data, track details, and sales revenue.
Tools Used
Database: Chinook SQLite (Chinook_Sqlite.sqlite) Program: DB Browser for SQLite
Platform: GitHub
What I Did So Far
Day 1: 
 Counted the total number of customers and listed their countries.
 Found the top 10 longest tracks and searched for tracks with the word "Love".

Filtered customers from Brazil and Canada, and checked high invoices in 2012.

Day 2: Grouping Data (GROUP BY)

 Calculated total store sales and found the top 10 countries by revenue.

Checked the number of invoices and average sales per year.
 
Found countries with 5 or more customers, top 5 customers by spending, and monthly sales for 2013.
